적립 내역 대조 · 기기 진단

실제 지급 자동 조회 아님

서비스에서 직접 다운로드한 적립 내역 CSV를 선택하여 이 앱에 기록된 보상과 대조합니다. CSV에 포함된 금액은 바로 수익에 합산하지 않습니다. 개인정보가 포함된 원본은 기기에만 남으며 서버로 전송하지 않습니다.

지원 CSV: 날짜, 미션, 적립금_원상당 (앱테크 운영실 내보내기 형식). 외부 앱의 CSV는 열 이름을 맞춰 별도 저장한 뒤 사용하세요.

대조할 파일을 선택하세요.

WebRTC 동기화는 수동 신호 교환이 필요합니다. 한 기기에서 데이터 변경 후 서로 양방향 전송해야 합니다. 실시간 백그라운드 동기화가 아닙니다.

v6.0 · 배포 및 데이터 무결성 진단

검증 도구

홈 화면 설치·오프라인 캐시는 HTTPS 또는 localhost 배포에서만 지원됩니다. 파일로 열었을 때 설치 기능이 제한될 수 있습니다. 진단 결과는 현재 이 브라우저 기준입니다.

실제 지급 검증: 공식 API로 조회하는 기능은 제공되지 않습니다. CSV 내역 대조는 사용자가 가져온 자료의 비교일 뿐, 발행기관 인증이 아닙니다.

헤더: 날짜,미션,적립금_원상당,상태 (상태: 지급,대기,취소). 상태를 생략하면 미확인으로 처리합니다. 동일 날짜·미션·금액 건은 발생 횟수별로 순서대로 대조합니다.

내역 파일을 선택하면 대조합니다.

v9.0 · 지급 확인 현황·동기화 충돌 감사

추정 수익과 확정 수익 분리

CSV 상태는 발급자가 제공한 문서의 표기일 뿐 현금 입금 증명이 아닙니다. 지급, 대기, 취소, 미확인을 분리하고, 실제 입금 확인액은 별도 집계해야 합니다.

CSV의 날짜,미션,적립금_원상당,상태 열을 가져오세요.

기기 간 자동 동기화는 제공되지 않습니다. 충돌 감사는 다른 기기에서 가져온 JSON과 현재 기록을 비교하며 원본을 변경하지 않습니다.

원본 보존 우선

백업에서 새 ID만 병합하고, 동일 ID의 내용이 다르거나 같은 내용을 다른 ID로 저장한 후보는 자동으로 덮어쓰지 않습니다. 병합 전에 현재 데이터 백업을 다운로드합니다. 복구가 필요하면 기존 백업 불러오기를 사용하세요.
